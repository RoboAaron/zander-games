# Shark art prompts (for Nano Banana / Gemini image, or any image model)

The illustrations in `sharks/art/` were generated from the prompts below. Each one
is the **shared style block** + a **per-species description**. Keep the style block
identical for every shark so the whole set stays consistent, then swap in the
species line. Generate at **4:3**, then resize to ~860 px wide WebP for the game.

## Shared style block (append to every prompt)

> Semi-realistic children's educational encyclopedia illustration, full-body side
> profile facing left and swimming, clean bold dark outlines, smooth soft cel
> shading, anatomically accurate proportions and markings, centered composition,
> plain soft gradient teal-to-deep-blue underwater background with gentle god-ray
> light beams and a few small bubbles, flat poster-like, no text, no watermark, no
> border, no frame, cohesive style matching a set of shark trading cards.

Tip for consistency in Nano Banana: generate the great white first, then attach it
as a **style reference image** for the rest while changing only the species line.
