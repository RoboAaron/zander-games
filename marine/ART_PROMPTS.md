# Sea life art prompts (for Nano Banana / Gemini image, or any image model)

The illustrations in `marine/art/` were generated from the prompts below. Each one
is the **shared style block** + a **per-species description**. Keep the style block
identical for every creature so the whole set stays consistent, then swap in the
species line. Generate at **4:3**, then resize to ~860 px wide WebP for the game.

Use a shark illustration from `sharks/art/` (e.g. `great-white.webp`) as a **style
reference image** so the marine set matches the shark spotter art.

## Shared style block (append to every prompt)

> Semi-realistic children's educational encyclopedia illustration, full-body view
> of the animal as the clear main subject, clean bold dark outlines, smooth soft
> cel shading, anatomically accurate proportions and markings, centered composition,
> plain soft gradient teal-to-deep-blue underwater background with gentle god-ray
> light beams and a few small bubbles, flat poster-like, no text, no watermark, no
> border, no frame, cohesive style matching a set of marine life trading cards
> that match the shark encyclopedia illustrations.

For swimming animals, prefer a side profile facing left. For bottom-dwellers
(crabs, lobsters, sea stars, urchins, clams), use a clear three-quarter or top-down
view that shows the species' key features.
